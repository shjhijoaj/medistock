# MediStock

## 项目背景

从前端 Web 课程实践出发，完成药品、供应商、入库、出库与库存统计流程，进一步以批次数据和业务单据支撑完整的进销存工作台。

## 数据链路

Vue 业务工作台 → Node.js 接口 → FEFO 分配 → 库存 / 单据事务 → SQLite

## 关键问题

请求重试时，怎样避免库存被扣两次？

服务端在事务内处理库存与单据，并保存唯一幂等请求标识。相同标识与内容重复提交时复用原结果，不重复扣减；同标识但不同内容则拒绝。HTTP 集成验收覆盖并发超库存与幂等重试。

## 验证

- 8 项库存规则测试及 HTTP 集成验收通过。
- 实际浏览器完成药品、供应商、入库、跨批次出库和单据追溯。
- 记录覆盖库存不足回滚、并发出库、重启持久化与非法备份拒绝。
